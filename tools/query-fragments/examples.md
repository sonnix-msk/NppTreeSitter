# Размеченные примеры: фрагмент запроса или обычная строка?

Синтетические примеры для проверки/тюнинга детектора (`query_scan.py`).
Все — без данных реальных конфигураций. Порог по умолчанию — **0.30**.

## Должны детектиться как ЗАПРОС

| Текст в литерале | Оценка | Что сработало |
|---|---|---|
| `ВЫБРАТЬ Т.Ссылка ИЗ Справочник.Товары КАК Т` | 0.917 | metadata, kw:выбрать, kw:из |
| `ВЫБРАТЬ Т.Поле КАК П СГРУППИРОВАТЬ ПО Т.Поле` | 0.989 | kw:сгруппировать |
| `ВЫБРАТЬ основание` | 0.400 | kw:выбрать (капс, одно слово) |
| `выбрать наименование из справочник.товары` | 0.696 | metadata (регистр-независимо) |
| `Выбрать * Из ВТМояВременнаяТаблица` | 0.330 | kw:выбрать, kw:из |
| `И Сотрудники.Ссылка = &Значение` | 0.523 | param:&, dotted |
| `... ПО Период ПЕРИОДАМИ(МЕСЯЦ)` | ~0.7 | strong_form periods_call |
| `ВЫБРАТЬ * ИЗ ВТ ... УПОРЯДОЧИТЬ ПО Т.Дата` | выс. | kw:упорядочить |

## Должны оставаться обычной СТРОКОЙ

| Текст в литерале | Оценка | Почему не запрос |
|---|---|---|
| `выбрать всякую фигню` | 0.140 | одна строчная лексема, нет структуры |
| `где ты был` | 0.122 | строчные, нет структуры |
| `Выбрать основание` | 0.240 | смешанный регистр (UI-подпись) |
| `Из ККТ` | 0.180 | одна строчная лексема |
| `Письмо отмечено как спам` | 0.087 | только «как», строчные |
| `ООО Ромашка, ИНН/КПП` | 0.000 | капс, но не лексикон запроса |
| `В указанном периоде отчета есть изменения` | 0.117 | проза, слова не в роли ключевых |

## Ключевые инварианты (не ломать при тюнинге)

1. **Регистр — модификатор, не фильтр.** `выбрать` строчными даёт вклад (0.14), но
   одиночное слово порог не берёт; в связке с `из справочник.товары` — берёт (0.696).
2. **Одиночная строчная лексема не проходит порог.** Иначе «выбрать файл» ловилось бы как запрос.
3. **Путь по типу метаданных** (`Справочник.`, `Документ.`, …) весит 0.60 и регистронезависим —
   это то, что отличает «выбрать наименование из справочник.товары» от «выбрать всякую фигню».
4. **`&Параметр`** вес понижен до 0.40: встречается и в обычных BSL-выражениях.
5. **Длина текста не должна повышать оценку** — формула «сильнейший + затухающий бонус»,
   а не `1−∏(1−w)` (та награждала длину, и проза обгоняла запрос).
6. **`ПЕРИОДАМИ(`** (из блока `ИТОГИ … ПО …`) — сильная форма (0.60). Само слово
   `периодами` — обычное русское, вес низкий (0.15).

## Замер на реальном корпусе

7 модулей, 15 МБ, 18 921 строковый литерал/группа (локальный корпус, вне репозитория):

| Полоса | Доля |
|---|---|
| `>= 0.75` (уверенно запрос) | 7.2 % |
| `0.30–0.75` (детектируется) | 2.9 % |
| `< 0.15` (обычные строки) | 89.0 % |

Порог **0.30** подтверждён пользователем как рабочий на этом корпусе.
